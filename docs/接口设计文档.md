## 1. 接口规范

### 1.1 通用约定

| 项目 | 规范 |
|------|------|
| 协议 | HTTP/HTTPS |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |
| 请求方式 | RESTful风格 |
| 版本控制 | URL路径中包含版本号 `/api/v1` |
| 时间格式 | ISO 8601: `yyyy-MM-dd HH:mm:ss` |
| 日期格式 | `yyyy-MM-dd` |

### 1.2 响应格式

**成功响应：**

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1716979200000,
  "traceId": "abc123def456"
}
```

**错误响应：**

```json
{
  "code": 400,
  "message": "参数错误：店铺ID不能为空",
  "data": null,
  "timestamp": 1716979200000,
  "traceId": "abc123def456"
}
```

### 1.3 HTTP状态码

| 状态码 | 含义 | 使用场景 |
|--------|------|----------|
| 200 | OK | 请求成功 |
| 400 | Bad Request | 请求参数错误 |
| 404 | Not Found | 资源不存在 |
| 429 | Too Many Requests | 请求过于频繁，触发限流 |
| 500 | Internal Server Error | 服务器内部错误 |

### 1.4 业务状态码

| 状态码 | 含义 | 说明 |
|--------|------|------|
| 200 | 成功 | 请求处理成功 |
| 400001 | 参数校验失败 | 请求参数不符合规范 |
| 400002 | 资源不存在 | 查询的资源不存在 |
| 400003 | 数据已存在 | 重复添加 |
| 500001 | 系统内部错误 | 服务器异常 |
| 500002 | 数据库错误 | 数据库操作失败 |
| 500003 | 缓存错误 | Redis操作失败 |

## 6. 数据模型

### 6.1 ShopVO (店铺视图对象)

```json
{
  "shopId": "string",           // 店铺唯一标识
  "name": "string",             // 店铺名称
  "category": "string",         // 分类编码
  "categoryName": "string",     // 分类名称
  "rating": "number",           // 评分 (0-5)
  "priceAvg": "integer",        // 人均消费
  "address": "string",          // 地址
  "longitude": "number",        // 经度
  "latitude": "number",         // 纬度
  "phone": "string",            // 电话
  "businessHours": "string",    // 营业时间
  "tags": ["string"],           // 标签数组
  "source": "string",           // 数据来源
  "viewCount": "integer",       // 浏览次数
  "rank": "integer",            // 排名（排行榜接口）
  "distance": "number",         // 距离（周边接口）
  "costPerformance": "number",  // 性价比指数
  "createTime": "string",       // 创建时间
  "updateTime": "string"        // 更新时间
}
```

### 6.2 SpotVO (景点视图对象)

```json
{
  "spotId": "string",           // 景点唯一标识
  "name": "string",             // 景点名称
  "longitude": "number",        // 经度
  "latitude": "number",         // 纬度
  "description": "string",      // 景点介绍
  "hotScore": "integer",        // 热度评分
  "createTime": "string"        // 创建时间
}
```

### 6.3 PageResult (分页结果)

```json
{
  "list": [],                   // 数据列表
  "page": "integer",            // 当前页码
  "size": "integer",            // 每页数量
  "total": "integer",           // 总记录数
  "pages": "integer"            // 总页数
}
```

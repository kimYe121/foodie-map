## 3. 数据表设计

### 3.1 店铺表 (t_shop)

**表说明：** 存储美食店铺基础信息

| 字段名 | 数据类型 | 长度 | 是否为空 | 默认值 | 说明 |
|--------|----------|------|----------|--------|------|
| id | BIGINT | - | NOT NULL | AUTO_INCREMENT | 主键，自增ID |
| shop_id | VARCHAR | 50 | NOT NULL | - | 店铺唯一标识（业务主键） |
| **city** | **VARCHAR** | **20** | **NOT NULL** | **-** | **所属城市（nanchang/wuhan/changsha）** |
| name | VARCHAR | 100 | NOT NULL | - | 店铺名称 |
| category | VARCHAR | 50 | NULL | - | 美食分类 |
| address | VARCHAR | 255 | NULL | - | 详细地址 |
| longitude | DECIMAL | 10,7 | NULL | - | 经度（-180~180） |
| latitude | DECIMAL | 10,7 | NULL | - | 纬度（-90~90） |
| rating | DECIMAL | 2,1 | NULL | 0.0 | 综合评分（0.0-5.0） |
| price_avg | INT | - | NULL | 0 | 人均消费（元） |
| phone | VARCHAR | 20 | NULL | - | 联系电话 |
| business_hours | VARCHAR | 100 | NULL | - | 营业时间 |
| tags | VARCHAR | 255 | NULL | - | 标签，逗号分隔 |
| source | VARCHAR | 20 | NULL | - | 数据来源（dianping/meituan） |
| view_count | INT | - | NULL | 0 | 浏览次数 |
| create_time | DATETIME | - | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | - | NOT NULL | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**约束：**
```sql
PRIMARY KEY (id),
UNIQUE KEY uk_shop_id (shop_id),
KEY idx_city (city),
KEY idx_category (category),
KEY idx_rating (rating),
KEY idx_price (price_avg),
KEY idx_location (longitude, latitude),
KEY idx_source (source),
KEY idx_create_time (create_time)
```

**表结构SQL：**
```sql
CREATE TABLE t_shop (
    id BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    shop_id VARCHAR(50) NOT NULL COMMENT '店铺唯一标识',
    city VARCHAR(20) NOT NULL COMMENT '所属城市（nanchang/wuhan/changsha）',
    name VARCHAR(100) NOT NULL COMMENT '店铺名称',
    category VARCHAR(50) DEFAULT NULL COMMENT '美食分类（动态生成）',
    address VARCHAR(255) DEFAULT NULL COMMENT '详细地址',
    longitude DECIMAL(10,7) DEFAULT NULL COMMENT '经度',
    latitude DECIMAL(10,7) DEFAULT NULL COMMENT '纬度',
    rating DECIMAL(2,1) DEFAULT 0.0 COMMENT '综合评分(0-5)',
    price_avg INT DEFAULT 0 COMMENT '人均消费(元)',
    phone VARCHAR(20) DEFAULT NULL COMMENT '联系电话',
    business_hours VARCHAR(100) DEFAULT NULL COMMENT '营业时间',
    tags VARCHAR(255) DEFAULT NULL COMMENT '标签，逗号分隔',
    source VARCHAR(20) DEFAULT NULL COMMENT '数据来源',
    view_count INT DEFAULT 0 COMMENT '浏览次数',
    shop_image VARCHAR(500) DEFAULT NULL COMMENT '店铺封面图片URL（阿里云OSS地址）',
    images TEXT DEFAULT NULL COMMENT '店铺图片列表（JSON数组，存OSS URL）',
    food_images TEXT DEFAULT NULL COMMENT '美食图片列表（JSON数组，存OSS URL）',
    video_url VARCHAR(500) DEFAULT NULL COMMENT '关联视频URL（阿里云OSS地址）',
    like_count INT DEFAULT 0 COMMENT '点赞数',
    comment_count INT DEFAULT 0 COMMENT '评论数',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_shop_id (shop_id),
    KEY idx_category (category),
    KEY idx_rating (rating),
    KEY idx_price (price_avg),
    KEY idx_location (longitude, latitude),
    KEY idx_source (source),
    KEY idx_create_time (create_time)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='店铺信息表';
```

### 3.3 店铺景点关联表 (t_shop_spot)

**表说明：** 存储店铺与景点的关联关系及距离

| 字段名 | 数据类型 | 长度 | 是否为空 | 默认值 | 说明 |
|--------|----------|------|----------|--------|------|
| id | BIGINT | - | NOT NULL | AUTO_INCREMENT | 主键，自增ID |
| shop_id | VARCHAR | 50 | NOT NULL | - | 店铺ID（外键） |
| spot_id | VARCHAR | 50 | NOT NULL | - | 景点ID（外键） |
| distance | DECIMAL | 5,2 | NULL | - | 距离（公里） |
| create_time | DATETIME | - | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |

**约束：**
```sql
PRIMARY KEY (id),
UNIQUE KEY uk_shop_spot (shop_id, spot_id),
KEY idx_spot_id (spot_id),
KEY idx_distance (distance)
```

**表结构SQL：**
```sql
CREATE TABLE t_shop_spot (
    id BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    shop_id VARCHAR(50) NOT NULL COMMENT '店铺ID',
    spot_id VARCHAR(50) NOT NULL COMMENT '景点ID',
    distance DECIMAL(5,2) DEFAULT NULL COMMENT '距离（公里）',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_shop_spot (shop_id, spot_id),
    KEY idx_spot_id (spot_id),
    KEY idx_distance (distance),
    CONSTRAINT fk_shop FOREIGN KEY (shop_id) REFERENCES t_shop(shop_id),
    CONSTRAINT fk_spot FOREIGN KEY (spot_id) REFERENCES t_spot(spot_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='店铺景点关联表';
```

| t_shop_spot | idx_distance | 普通 | distance | 距离排序 |

### 5.2 索引设计说明

```sql
-- 1. 排行榜查询优化
-- 查询：SELECT * FROM t_shop WHERE category = 'jiangxi' ORDER BY rating DESC LIMIT 10
-- 索引：idx_category + idx_rating（复合索引更优）

-- 2. 地图范围查询优化
-- 查询：SELECT * FROM t_shop WHERE longitude BETWEEN 115.8 AND 115.9 AND latitude BETWEEN 28.6 AND 28.7
-- 索引：idx_location（空间索引，MySQL 8.0支持空间数据类型）

-- 3. 景点周边查询
-- 查询：SELECT s.*, ss.distance FROM t_shop s JOIN t_shop_spot ss ON s.shop_id = ss.shop_id 
--       WHERE ss.spot_id = 'tengwangge' ORDER BY ss.distance LIMIT 20
-- 索引：t_shop_spot.idx_spot_id + t_shop_spot.idx_distance
```

## 7. 常用查询SQL

### 7.1 排行榜查询

```sql
-- 综合评分榜 TOP 10
SELECT * FROM t_shop 
WHERE rating > 0 
ORDER BY rating DESC, view_count DESC 
LIMIT 10;

-- 性价比榜 TOP 10（评分/价格）
SELECT *, (rating / NULLIF(price_avg, 0) * 100) as cost_performance 
FROM t_shop 
WHERE rating > 0 AND price_avg > 0 
ORDER BY cost_performance DESC 
LIMIT 10;

-- 分类排行榜（江西菜）
SELECT * FROM t_shop 
WHERE category = 'jiangxi' AND rating > 0 
ORDER BY rating DESC 
LIMIT 10;
```

### 7.2 地图查询

-- 景点周边美食（滕王阁周边3公里）

### 7.3 统计查询

```sql
-- 各分类店铺数量统计
SELECT category, COUNT(*) as count, AVG(rating) as avg_rating 
FROM t_shop 
GROUP BY category 
ORDER BY count DESC;

-- 价格区间分布
SELECT 
    CASE 
        WHEN price_avg < 30 THEN '便宜(<30)'
        WHEN price_avg < 60 THEN '适中(30-60)'
        WHEN price_avg < 100 THEN '稍贵(60-100)'
        WHEN price_avg < 200 THEN '贵(100-200)'
        ELSE '很贵(>200)'
    END as price_range,
    COUNT(*) as count
FROM t_shop 
GROUP BY price_range;
```

### 3.1 排行榜设计

#### 3.1.1 Redis数据结构

```
# 综合评分榜 - Sorted Set
Key: food:rank:overall
Score: 评分 (rating)
Member: 店铺ID (shop_id)

# 性价比榜 - Sorted Set
Key: food:rank:cost_performance
Score: 性价比指数 (rating/price * 100)
Member: 店铺ID (shop_id)

# 热门榜 - Sorted Set
Key: food:rank:hot
Score: 浏览量 (view_count)
Member: 店铺ID (shop_id)

# 分类榜 - 按分类分桶
Key: food:rank:category:{category_code}
Score: 评分 (rating)
Member: 店铺ID (shop_id)

# 店铺详情 - Hash
Key: food:shop:{shop_id}
Field: 各字段名
Value: 字段值

# 店铺坐标 - Geo
Key: food:shop:geo
Member: 店铺ID
Position: (longitude, latitude)
```

#### 3.4.4 上传流程

**爬虫端上传（Python）：**

```python
# Scrapy Pipeline 实现
class OssUploadPipeline:
    """爬虫图片上传到阿里云 OSS"""

    def __init__(self, oss_config):
        self.bucket = oss2.Bucket(
            oss2.Auth(oss_config['access_key'], oss_config['secret_key']),
            oss_config['endpoint'],
            oss_config['bucket_name']
        )

    def process_item(self, item, spider):
        # 1. 下载图片到临时目录
        image_path = self.download_image(item['image_url'])
        # 2. 上传到 OSS，路径: shop/cover/{shop_id}/main.jpg
        oss_key = f"shop/cover/{item['shop_id']}/main.jpg"
        self.bucket.put_object_from_file(oss_key, image_path)
        # 3. 生成 OSS 访问 URL，写入 item
        item['shop_image'] = f"https://foodie-map-img.oss-cn-nanchang.aliyuncs.com/{oss_key}"
        # 4. 清理临时文件
        os.remove(image_path)
        return item
```

**后端签名上传（Java）：**

```java
// 前端直传 OSS，后端生成签名 URL
@RestController
public class OssController {

    @GetMapping("/api/v1/oss/sign-upload")
    public Result<String> getSignUploadUrl(@RequestParam String filename) {
        // 生成带签名的上传 URL（有效期 10 分钟）
        String ossKey = "shop/cover/" + UUID.randomUUID() + "/" + filename;
        String signedUrl = ossService.generateSignedUploadUrl(ossKey, 600);
        return Result.success(signedUrl);
    }
}
```

| PUT/GET 请求 | 约 10 万次/月 | 0.01 元/万次 | ≈ 1 元 |
| **月总费用** | | | **≈ 12 元** |

> 注：阿里云学生免费套餐通常包含 20GB 存储 + 20GB 流量/月，本项目用量在免费额度内。

#### 3.4.7 安全配置

| 安全措施 | 实现方式 |
|----------|----------|
| 上传鉴权 | 后端生成 STS 临时凭证，前端直传 OSS |
| 防盗链 | OSS 设置 Referer 白名单，仅允许项目域名访问 |
| 文件类型校验 | 仅允许 jpg/png/gif/webp，拒绝可执行文件 |
| 文件大小限制 | 单张图片最大 5MB |
| 访问控制 | 公共读 Bucket，私有写操作需签名 |

## 9. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 爬虫被封 | 数据采集中断 | IP代理池、请求频率控制、多源备份 |
| Redis故障 | 排行榜不可用 | 降级策略、直接查数据库 |
| 数据量过大 | 性能下降 | 分页查询、索引优化、分库分表（未来） |
| 地图API超限 | 坐标转换失败 | 本地缓存坐标、多Key备用 |
| OSS服务不可用 | 图片无法显示 | 数据库保留原始URL备份，前端图片加载失败时显示默认占位图 |
| OSS额度超限 | 图片上传失败 | 监控存储用量，定期清理无用图片，压缩图片体积 |
